
# Project 4: AWS Three-Tier Architecture

## Project Overview
This project demonstrates a three-tier cloud architecture using AWS services.

## Project Objective
To understand secure and scalable cloud infrastructure design.

## Technologies Used
- AWS VPC
- Public Subnet
- Private Subnet
- EC2
- RDS
- Security Groups
- Internet Gateway

## Project Architecture
User -> Web Tier -> Application Tier -> Database Tier

## Implementation Steps
1. Create an AWS VPC.
2. Create public and private subnets.
3. Configure Internet Gateway.
4. Configure route tables.
5. Launch EC2 instances.
6. Configure RDS database.
7. Configure security groups.
8. Test application connectivity.

## Expected Outcome
A basic three-tier architecture deployed in AWS.
