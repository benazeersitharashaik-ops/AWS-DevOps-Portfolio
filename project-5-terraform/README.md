
# Project 5: AWS Infrastructure using Terraform

## Project Overview
This project demonstrates Infrastructure as Code using Terraform.

## Project Objective
To create and manage AWS infrastructure using Terraform configuration files.

## Technologies Used
- AWS
- Terraform
- Linux
- Git
- GitHub

## Project Architecture
Terraform -> AWS Provider -> AWS Infrastructure

## Implementation Steps
1. Install Terraform.
2. Configure AWS credentials securely.
3. Create Terraform configuration files.
4. Configure AWS provider.
5. Define infrastructure resources.
6. Execute terraform init.
7. Execute terraform plan.
8. Execute terraform apply.
9. Verify AWS resources.
10. Clean up resources using terraform destroy.

## Expected Outcome
Automated AWS infrastructure provisioning using Terraform.
