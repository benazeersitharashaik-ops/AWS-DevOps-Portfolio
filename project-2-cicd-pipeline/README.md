
# Project 2: CI/CD Pipeline using Jenkins

## Project Overview
This project demonstrates Continuous Integration and Continuous Deployment using Jenkins.

## Project Objective
To automate application build and deployment using Jenkins and GitHub.

## Technologies Used
- AWS EC2
- Jenkins
- Git
- GitHub
- Docker
- Linux

## Project Architecture
Developer -> GitHub -> Jenkins -> Docker -> Deployment

## Implementation Steps
1. Create a GitHub repository.
2. Configure Jenkins on AWS EC2.
3. Connect GitHub with Jenkins.
4. Create a Jenkins Pipeline.
5. Configure build stages.
6. Build Docker image.
7. Deploy the application automatically.

## Expected Outcome
Automated application build and deployment using a CI/CD pipeline.
