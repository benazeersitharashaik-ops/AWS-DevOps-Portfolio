
# Project 1: AWS Static Website Deployment

## Project Overview
This project demonstrates how to build and deploy a static website using AWS and DevOps tools.

## Project Objective
To understand website hosting, containerization, and cloud deployment using Docker and AWS EC2.

## Technologies Used
- HTML
- CSS
- Git
- GitHub
- Docker
- Docker Hub
- AWS EC2
- Linux

## Project Architecture
Developer -> GitHub -> Docker -> Docker Hub -> AWS EC2 -> Website

## Implementation Steps
1. Created a static website using HTML and CSS.
2. Uploaded source code to GitHub.
3. Created a Dockerfile.
4. Built a Docker image.
5. Pushed the image to Docker Hub.
6. Pulled the image into AWS EC2.
7. Deployed the website using Docker.

## Expected Outcome
A static website accessible through an AWS EC2 public IP address.
